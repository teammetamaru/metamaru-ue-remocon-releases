# METAMARU UE 리모콘 — 배포 저장소

이 저장소는 **배포 전용**입니다. 소스 코드는 없습니다.

- **Releases** — 안드로이드 APK. 앱이 시작할 때 최신 Release를 확인해 자동 업데이트합니다.
  APK는 팀 고정 키로 서명되어 있어, 다른 키로 서명된 APK는 업데이트로 설치되지 않습니다.
- **layouts/** — 프로젝트별 버튼 레이아웃. 키코드로 **AES-256-GCM 암호화**되어 있고
  파일 이름도 키코드에서 파생되므로, 키코드 없이는 내용이나 프로젝트를 알 수 없습니다.

레이아웃 추가/수정은 소스 저장소의 `tools/publish_layout.dart`로만 하세요 (직접 편집 금지).
